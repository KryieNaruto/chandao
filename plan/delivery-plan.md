# 交付计划

## 需求原文

1. 按钮样式颜色扁平化，不需要中心白色的渐变。
2. 添加窗口拖拽功能，左上角关闭按钮移动到右上角，同时添加按钮关闭功能，此时并非关闭，而是最小化到托管栏，真正的退出需要右键小图标点击退出。
3. 刻度中间留的空，现在需要加东西，我现在初步规划两种，一个是数字剩余时间，第二个是一个会生长的植物。后者先不做，但是需要留出模式切换的扩展余地。
4. 添加逻辑：
   1）当计时到了后，进入休息计时阶段，这个时间设置为10s方便测试。样式是刻度原有颜色按照顺时针，进度条的方式改变刻度颜色。即将计时的颜色表达反过来即可，计时是灰->蓝，休息计时蓝->灰
   2) 计时到后，弹出窗口。

## 需求对齐结论（用户已确认）

- 「托管栏」= Windows 系统托盘；点击关闭按钮 → 隐藏到托盘；右键托盘图标菜单「退出」才真正关闭。
- 「弹出窗口」= 全屏半透明遮罩提醒窗口，显示「休息一下」+ 剩余秒数，休息结束自动关闭。
- 中心数字：工作与休息阶段都显示剩余秒数，颜色随阶段变化。
- 窗口拖拽上一轮已实现，本轮保留不重复开发。
